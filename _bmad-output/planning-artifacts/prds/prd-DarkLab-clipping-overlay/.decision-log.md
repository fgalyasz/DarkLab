# Decision log — prd-DarkLab-clipping-overlay

## 2026-10-31 — Histogram half of story 3.4 already ships

Develop and Library already call the histogram widget with the Preview. This slice adds a test that an exposure change moves the histogram and builds the missing overlay.

## 2026-10-31 — Any channel counts as clipped

The Classic overlay marks a pixel when one channel clips, which is what hides detail in a color channel. Highlights win over shadows for a pixel that is both.

## 2026-10-31 — Overlay is a view only

The toggle is a checkable button next to Before/After. It never enters the History, the sliders, or the Catalog.
