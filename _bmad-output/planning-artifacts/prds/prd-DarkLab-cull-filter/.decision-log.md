# Decision log — prd-DarkLab-cull-filter

## 2026-10-29 — Pure matching in the Catalog layer

Filter rules (Rating, Flag, Color Label) live in `src/catalog/cull_filter.py` with no Qt import. The panel only reads the combo values and passes the grid's marker map. Rating matching moved there from `src/ui/library_catalog.py` so there is one owner.

## 2026-10-29 — Unmarked Photos count as no marks

A Photo missing from the marker map is treated as Rating 0, Flag none, Color none, the same defaults the Catalog reads.

## 2026-10-29 — Filter does not refresh on a mark change

Changing a mark while a filter is active leaves the Photo in view until the next refresh, so a cull pass does not make Photos vanish under the cursor. Revisit if the Photographer asks for live narrowing.

## 2026-10-29 — Contrast is computed, not eyeballed

NFR-7 is checked by parsing the body QWidget background and QLabel color from the stylesheet and computing the WCAG ratio. The check covers the shared Library and Import stylesheets.
