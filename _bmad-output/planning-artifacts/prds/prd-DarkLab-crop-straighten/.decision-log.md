# Decision log — prd-DarkLab-crop-straighten

## 2026-10-30 — Numeric controls first

A draggable overlay needs hit-testing and handles. Story 3.2's acceptance criteria are about stored state, the lock, and Reset, so this slice ships numeric controls in the Develop panel. The overlay is a later slice.

## 2026-10-30 — Edges are percent trimmed

Percent of each side keeps the stored crop independent of the image size, so the same crop is valid for the Preview and for a full-size Export.

## 2026-10-30 — Lock keeps the Original ratio

Left plus Right trimmed equals Top plus Bottom trimmed keeps the Original ratio. That rule needs no ratio list.

## 2026-10-30 — Box on the rotated canvas

Rotating with canvas growth keeps every pixel of the Original reachable. Preview and Export share one box function so they cannot disagree.
