## 2026-10-10 — A Catalog is required

Ferenc corrected the earlier cancel behavior. Lightroom does not open the workspace without a Catalog, and DarkLab follows that. Select Catalog offers Open and New. Quit exits. A missing recent Catalog now asks; it no longer stays silent. Recent mode with a file still opens that file without asking.

This reverses the FR-48 consequence "cancel leaves no Catalog current" and "recent does not show a window when the file is missing." Captured as FR-50. Epic #48. Story #49.

## 2026-10-10 — Default stays recent

Ask is a choice, not the new default. A missing recent Catalog does not pop the Open Catalog window. A missing pinned Catalog does, because fixed mode promised a file and cannot keep that promise.

Captured in FR-48, FR-49, and SM-C3.

## 2026-10-10 — Pin is a path, not a lock

Opening another Catalog updates the recent path only. The pinned path changes only from Catalog Settings. The Photographer can change Startup Mode later. The stored pin survives a temporary switch to recent or ask.

Captured in FR-49.
