# Decision Log — prd-DarkLab-configurable-auto-cull

- **2026-11-11 — Local deterministic + lightweight CV metrics first:** To satisfy ADR-8 (offline shoot path) and NFR-5 (Windows, macOS, Linux lockstep), `src/culling/metrics.py` uses NumPy/OpenCV deterministic operators and bundled cascade/ONNX-ready adapters with graceful fallback when optional neural weights are absent.
- **2026-11-11 — Face-absent weight normalization:** If a Photo has no detected faces, eye and smile weights are excluded from the denominator rather than scored as zero, preventing landscape or detail shots in a wedding shoot from being auto-rejected.
- **2026-11-11 — Cache metrics by content_hash:** Storing raw metric vectors in `photo_cull_metrics` allows instant threshold/weight slider adjustments in the UI without re-reading image files.
