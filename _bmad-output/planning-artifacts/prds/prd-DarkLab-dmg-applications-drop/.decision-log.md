# Decision log — DMG Applications drop window

## 2026-11-21 — Match WalkAway/SnappyZones staging layout

DarkLab used `hdiutil create -srcfolder` on the `.app` alone, so Finder showed only the bundle. Studio products that already ship a drop window stage the app next to `ln -s /Applications`, open a read-write UDRW image, set icon positions with AppleScript, then convert to UDZO. Reuse that path without a custom background so CI stays headless-friendly when Finder layout fails (try blocks already ignore position errors).
