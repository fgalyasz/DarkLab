# Decision Log — prd-DarkLab-multi-photo-manipulation

- **2026-11-11 — Distinguish static Sync from per-photo computed Batch operations:** Synchronizing static sliders (`Sync...`) copies the Primary Photo's numbers, whereas Batch Auto-Tone, Batch Auto-Crop, and Batch AI Corrections evaluate the respective detector/solver independently on each selected Photo so framing and tone adapt to each frame.
- **2026-11-11 — Single transaction per Photo with History Step:** Each modified Photo in a batch writes its merged `develop_settings` and appends a History Step atomically so canceling a 200-photo batch at photo 80 leaves photos 1–80 cleanly updated and 81–200 untouched.
