# Decision log — prd-DarkLab-catalog-folders

## 2026-10-31 — Folders come from stored Original paths

The `folders` table only records import-time parents and would not follow a relink. Grouping Photos by the parent of their stored path always agrees with the grid and needs no migration.

## 2026-10-31 — Flat list instead of a tree

Story 2.2 asks for the directories of the Originals as Folders. A flat list with counts covers selecting and missing marks. The disk browser tree it replaces listed directories that held no Photos and ignored the selection.

## 2026-10-31 — Relink is all or nothing

A partial relink would leave one Folder split across two directories. Every file is checked first and the paths are written in one transaction.

## 2026-10-31 — Different content is refused in the UI

The photo-level relink already treats different content as an explicit confirmation. The Folder dialog stays on the safe side until a confirmation dialog is designed.
