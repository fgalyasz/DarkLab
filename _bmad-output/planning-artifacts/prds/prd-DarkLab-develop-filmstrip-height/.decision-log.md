# Decision log — Develop filmstrip height

## 2026-11-21 — Icon-only cells; hide DisplayRole text

Screenshot analysis showed ~8 px of colorful thumbnail inside a ~90 px filmstrip chrome: QListView IconMode was laying out decoration + `path.name` in a 78 px-tall grid, crushing the icon. Lightroom’s strip is icon-first. Clear DisplayRole, keep ToolTipRole, and raise cell/icon/widget heights so portraits and landscapes both read clearly.

## 2026-11-21 — Custom FilmstripDelegate; Fixed resize mode

After the first fix, macOS still drew ant-wide slivers spaced across the strip: `ResizeMode.Adjust` ignored usable icon geometry when DisplayRole was empty. A `FilmstripDelegate` paints the scaled pixmap into `CELL_SIZE`, `SizeHintRole` returns that size, and resize mode is `Fixed`.
