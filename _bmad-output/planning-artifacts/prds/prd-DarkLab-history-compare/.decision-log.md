# Decision log — prd-DarkLab-history-compare

## 2026-10-30 — Steps are session memory

The story's criteria walk Steps inside Develop. Persisting them needs a Catalog table and a migration, which belongs with Epic 22's schema work. Stored settings already survive restart.

## 2026-10-30 — One Step per settled change

The panel already saves after a short pause. Recording at that moment turns a slider drag into one Step.

## 2026-10-30 — Import settings are the defaults

DarkLab keeps no separate copy of the settings present at Import. Reset already treats the defaults as the Import state (FR-64), so Before/After does too.

## 2026-10-30 — Found while testing: duplicate slider titles

Develop has more than one slider titled Contrast and Highlights (for example in Effects). Tone save, load, and preview binding matched every slider with that title, so the last one won and an unrelated slider could be written as the photo's tone. They now use the first slider with each title, which is the Basic panel slider.
