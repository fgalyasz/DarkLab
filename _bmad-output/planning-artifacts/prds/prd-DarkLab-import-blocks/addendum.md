# Addendum — Import blocks

`_shaded_block` builds a `QFrame#importBlock` with `QLabel#importBlockTitle` and a body named `importBlockBody`. The Import stylesheet gives the title a gradient and the body a darker fill than the side column.

The top bar, bottom bar, source, stage, and side use `importTopBar`, `importBottomBar`, `importSource`, `importStage`, and `importSide`.

`_write_destination` updates the active destination preset. Other presets in `destination_presets` stay.
