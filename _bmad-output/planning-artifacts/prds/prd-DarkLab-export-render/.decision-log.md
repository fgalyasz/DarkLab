# Decision log — prd-DarkLab-export-render

## 2026-10-30 — One slice for stories 4.1, 4.2, 4.3, and 19.3

The render, the Presets, the no-ingest guarantee, and the dialog share one service. Splitting them would leave a dialog with no render or a render with no way to run it.

## 2026-10-30 — Export what the Preview shows

Only Exposure, Contrast, and crop change the Preview today. Export uses the same tone function and crop geometry, so a file never differs from what the Photographer approved on screen.

## 2026-10-30 — sRGB only

Adobe RGB and ProPhoto need ICC profiles the repo does not bundle. The Preset keeps a color-space field and ignores a stored value it cannot honour.

## 2026-10-30 — Presets live beside the Catalog

Saved Presets are a JSON file in the Catalog folder, so they move with it and need no schema change.

## 2026-10-30 — Replace the copy stub

The old Export button copied the 360-pixel index images. It is replaced, not kept.

## 2026-10-30 — Export runs on the UI thread

A first milestone shoot is a few hundred files and the dialog reports when it finishes. A background worker with progress is a later slice; the render service has no Qt import, so it moves without change.
