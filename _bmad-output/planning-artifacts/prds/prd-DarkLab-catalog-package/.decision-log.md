# Decision log — prd-DarkLab-catalog-package

## 2026-10-10 — The Catalog is a folder

Ferenc: the Catalog file or folder should contain what Classic keeps: imported photo folders, index images, DarkLab settings, and room for whatever else the Catalog will need.

Fast path. Captured as FR-51, FR-52, FR-53, and FR-54. Epic #50. Story #51.

The folder holds `catalog.sqlite`, `previews/`, and `settings.json`. Later rows (Develop Settings, Collections, Keywords, History Steps) go in the same database. This change does not add those tables.

## 2026-10-10 — Folders are records, not copies

Imported photo folders are paths stored in the Catalog. Originals stay on disk unless Import copies them. This matches the baseline rule that the Catalog references Originals. Rationale is in `addendum.md`.

## 2026-10-10 — Launch policy stays outside

Startup Mode, the recent path, and the pin stay in the application config (ADR-9, FR-48, FR-49). They choose a Catalog before that Catalog can be read. Catalog-scoped settings go in the folder (FR-54).

## 2026-10-10 — A previous single-file Catalog still opens

A Catalog created as one SQLite file before this change still opens. New Catalogs are folders. Do not rewrite the old file into a folder on open.
