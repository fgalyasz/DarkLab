# Decision log — prd-DarkLab-import-modes

## 2026-10-11 — Add was a separate box

Ferenc asked why Add sat apart from the other top-bar buttons. The caption "Add photos to catalog without moving them" lived in its own vertical box, so Add was no longer in the same row as Copy and Move. Assisted Culling had been placed in that row, between Move and Add.

Fast path. No new FR id. FR-5 already names Add, Copy, and Move as the three import methods.

## 2026-10-11 — Methods together, culling apart

Copy, Move, and Add are one group, in that order. Assisted Culling stays on the top bar, separated from the group, because it does not transfer a file. The caption stays under the group and is visible only while Add is selected.
