# Decision log — prd-DarkLab-library-sort

## 2026-10-31 — Sort on the stored Original, not the index image

The grid shows index images named by Photo id, so the old File Name sort ordered "1.jpg, 10.jpg, 2.jpg" and the old Capture Time sort used the index file's date, which is the Import moment. Both now read the Original.

## 2026-10-31 — Keys are read when the grid loads

Capture dates need a read of each Original's metadata. Reading once per load keeps filter typing and sort changes instant.

## 2026-10-31 — Capture Time is oldest first

Culling a shoot walks it in the order it was shot. The previous default was newest first.
