# Decision log

- Fast path. Story 22.2 (#92) already carries the acceptance criteria; the PRD only records them.
- Keep the SQLite rollback journal instead of WAL: a Catalog is a folder that users copy and back up, and WAL adds side files.
- The integrity check opens the database read-write once so a hot journal is rolled back before the read-only check. A read-only open cannot recover and reported a killed write as damage.
- Back up automatically into the default backup folder instead of prompting; the story allows either.
- The schema value stays an integer string in `catalog_meta`. Schema 1 to 2 is the first registered step.
