# Decision log — DarkLab auto-update

## 2026-11-21 — First-party GitHub Releases updater

Chose a stdlib `urllib` checker plus download/hand-off over embedding Sparkle/WinSparkle. One code path covers macOS, Windows, and Linux Community installers already published by the installer workflow. Pro channel stays out until Epic 16.

## 2026-11-21 — macOS opens DMG; Win/Linux schedule replace

macOS users already install from a signed DMG. Opening that image matches current distribution. Frozen Windows zip and Linux tar.gz layouts are folder bundles, so a short replace script after process exit is enough without an MSI/NSIS rewrite.

## 2026-11-21 — Startup check only when frozen

Quiet startup checks run only for packaged builds (`sys.frozen`). `python main.py` still has Help → Check for Updates (opens the asset URL). That keeps CI and local shell tests from hitting the live Releases API or modal dialogs.
