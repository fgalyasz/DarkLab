# Decision Log — prd-DarkLab-complete-develop-pipeline

- **2026-11-11 — Single NumPy/Pillow pipeline shared by Preview and Export (`src/imaging/pipeline.py`):** Per ADR-5, no Develop section may implement widget-only pixel math. Preview runs the exact same pipeline on the working preview resolution (or 1:1 crop tile for Detail), and Export runs it on the full-resolution decoded Original.
- **2026-11-11 — Fix duplicate SliderRow names in `detail_panel`:** `src/ui/develop_sections.py` previously used trailing spaces (`"Detail "`, `"Detail  "`, `"Contrast "`) which `.strip()` collapsed into duplicate `"Detail"` and `"Contrast"` titles. Story 24.4 assigns explicit key identifiers (`key: str`) to `SliderRow` while keeping clean display labels.
- **2026-11-11 — Persist History Steps and Snapshots in `catalog.sqlite`:** Storing `photo_history` and `photo_snapshots` in SQLite ensures full session recovery and snapshot management across restarts.
